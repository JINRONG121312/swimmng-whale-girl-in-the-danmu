# swimmng-whale-girl-in-the-danmu

大型连续剧之

**鲸鱼娘在弹幕群中游泳**

> 弹幕不是飘在画面上的字，弹幕**就是水**。
> 她游在弹幕里，因为有人在说话；没人说话，海就干了。

## 怎么演

下载或 clone 下来，**双击 `index.html`**。不用装东西、不用起服务、不用联网——离线打开海就是活的。

进来时海里有 22 条演示弹幕（那是她家原来的水），并且默认自播——每 0.9 到 2.4 秒随机飘进来一条（平均约 1.65 秒）。你可以：

| 你做什么 | 海和她会怎样 |
|---|---|
| 什么都不发，放着不管 | 水一点点退。水深跌破 96 px，她**搁浅**，趴在沙地上喊「水…… 谁来给点水……」 |
| 发一条弹幕 | 往海里加一方水：水位上涨、轨道变多、海床重新被淹 |
| 狂发 40 条以上 | 她**被弹幕淹没**，沉在海底只冒泡：「有人吗 我被淹在弹幕里了」 |
| 弹幕飘到她嘴边 | 她一口吞 3 条，饱食度 +42。吞得够多就**吃撑**：身体放大 34%、游速从 78 掉到 40、开始打嗝 |
| 她游过的地方 | 弹幕被她的身体**挤开**（最多 26 px）并跟着水流失重，离开时倾角回正 |
| 点一下「打赏」 | 礼物本身也是一条弹幕，得飘到她嘴边**被她吃掉**才算送到（小鱼干例外，落地就倒进海里加水） |

### 打赏

三个物件，形状不同、飘法一样：她从右往左撞上去，所以「送没送到」是玩法算出来的，不是按钮假装的。

| 礼物 | 形状 | 吃下去之后 | 叠法 |
|---|---|---|---|
| 爱心 | 一颗心形的弹幕 | 游得更快：每层 ×1.22，尾巴摆得越来越急 | 9 秒，最多 3 层 |
| 巧克力 | 一块会反光的方块 | 戴上墨镜，身体每层再胖 5% | 11 秒，最多 3 层 |
| 小鱼干 | 一条小鱼 | 不用她吃，直接给海倒水（+5 方） | 即时 |

没吃到的礼物就只是一条弹幕，飘过去就没了 —— 打赏不保底，这条和「水位 = 弹幕吞吐」是同一个设定。

### 她听得懂的词

只学了 6 组词，其余一律歪头。

| 你说 | 她做 |
|---|---|
| 哈哈 / 233 / xswl / 笑死 | 翻肚皮 |
| 救命 / sos / 捞捞 / 别沉 | 冲过去捞你 |
| 小鱼干 / 投喂 / 饿 / 吃 | 开始追食 |
| 加油 / 冲鸭 / 你可以 | 加速游（×1.85） |
| 上岸 / 搁浅 / 走走 | 歪头：「上面没有 wifi。」 |
| 离谱 / 绷不住 / 无语 | 急停，两眼变成一条线 |

被淹没的时候她**听不见**——她都淹了，这很合理。

### 连续剧壳

每 45 秒一集。本集标题取**她吃掉的第一条弹幕**（所以标题是观众共同作者），一条没吃就从兜底池抽一个《海干的下午》。换集时滚一行「剧情提要」，全部由真实事件拼出来：她吞了几条、有人笑了几次、海干了几个回合、她游过多少米。第 1 集有片头，片尾出下集预告。

## 面板

右下角「遥」打开**现场遥测**：水位、水深（带「← 搁浅线 96」的刻度提示）、同屏弹幕数、轨道数、她当前状态、饱食度、速度、本集时长、累计吞食。快捷键：`空格` 暂停 · `P` 面板 · `C` 证书 · `N` 回到输入框 · `Esc` 退出/关证书。

「奖」打开**参赛证书**（作品卡）：赛事与赛道、参赛者与团队、玩法、技术口径、实测体积、原创声明、许可、源码与部署地址；头部那枚奖牌条是同一批信息的一行摘要，窄屏自动缩成「奖牌 + 大赛名」。线上地址：https://whale-danmaku-sea-k9qghxjx4u5.qoder.website/

演示按钮（六个）用来**验证设定而不是装饰**：`刷「小鱼干」` 打三条带关键词的弹幕看她追食，`补水` 按 110 ms 一条塞 9 条看海面上升，`高能 46 条` 每 45 ms 一条逼出淹没，`断供` 关掉自播（海不会自己退，她得把水一条条吃掉才见得到沙地），`强制退潮` 是唯一让海自己退的开关，`弹幕自播` 一关就听得见「没人说话」是什么动静。

## 弹幕导入接口 —— 它不止是个游戏

`src/host.js` 是一个**平台无关**的归一化入口：任何平台、任何语言写的插件，只要能吐出
`{ nick, text, kind, gift }` 这个形状，就能把实时弹幕灌进这片海。页面零后端、`file://` 可跑，
**不碰任何平台账号、不收任何 token**，发送权限永远留在插件/服务端那边。

三条通路，挑一条：

| 通路 | 怎么开 | 适合谁 |
|---|---|---|
| 宿主直调 | `WWD.host.ingest(msg)` | OBS 浏览器源、Electron、注入脚本 |
| postMessage | 默认开着，`?allow=` 收紧来源 | 浏览器扩展 / 内容脚本 |
| WebSocket | `?ws=ws://127.0.0.1:8788` | 任何语言的本地桥（`scripts/bridge.js` 有一份零依赖的） |

协议 `proto: 1`：字段名按同义词表认（`text ← content|msg|message|body`…），令牌桶限流（默认
12 条/秒、突发 24），按 `id` 去重，认不出的礼物**降级成一条弹幕**而不是静默丢掉；往外有事件镜像
（`whale:eat` / `sea:drown` …）、2 秒一次的状态心跳、`reply` 反向互动通道，以及默认关闭、
`?ctl=1` 才生效的反向遥控。完整契约见 [`docs/host-api.md`](docs/host-api.md)。

B站 / 虎牙 / 抖音的**平台侧插件不在这个仓库里** —— 那部分要拿平台权限、要过合规，
按你自己的账号去写；这边只负责把吐进来的东西变成海。

## 技术与口径

- **零依赖、零构建**：传统 `<script>` 全局对象，没有 ES module、没有 `fetch`、没有 CDN、没有 `@font-face`。
- **体积**：7 个运行文件合计 **111.4 KB（未压缩）/ 42.2 KB（gzip）**。
- **弹幕宽度用 `canvas.measureText` 度量**，所以换字体得同步改度量字体栈，否则会叠字。
- **没有服务器**。你发出去的弹幕存在你自己的浏览器 `localStorage`（`wwd.danmu.v1`，上限 60 条），刷新后回放。昵称存在 `wwd.nick.v1`，字号/自播开关存在 `wwd.prefs.v1`。清掉浏览器数据，海就真的干了。
- **单一主循环**：一个 `requestAnimationFrame` 驱动海、她、剧本三方，`dt` 封顶 0.05 秒；标签页回到前台时重置时基。
- **循环不会死在第一帧**：后台标签页 / 还没显示的容器里开机时，首个 rAF 回调可能永不投递，而这类容器常常把定时器也一起冻住。所以有三条唤回路：1 秒一次的看门狗、`visibilitychange`、以及 `pointerdown / keydown / focus`（点一下就是页面真在被用的证据）。`WWD.snapshot().revives` 是它救场的次数。
- **她不会瞬移**：视口宽高变了（拖窗、旋转、软键盘、地址栏收起）就按新旧比例搬位置，搁浅是滑到沙地上而不是砸下去；`resize` 之后立刻重画一帧。
- **可达性**：`prefers-reduced-motion` 下关摆动与弹簧（JS 同步关闭，减少动效不减少信息），`forced-colors` 下弹幕保留 1px 描边、水色退成 `Canvas`；弹幕层与片头遮罩一律 `pointer-events: none`；窄屏的发送条与打赏栏高度由 JS 量出来写进 `--ui-h` / `--dock-h`，海的底边让给这条控件带 —— 她不会坐在输入框上，弹幕也不会流进输入框底下。
- 输入内容经过 HTML 转义，昵称与内容都有长度上限。

## 已知没做完的事（诚实清单）

- `prefers-reduced-motion` 和 `forced-colors` 只验证了**规则存在且 JS 侧有联动**，没在真实系统偏好下跑过（我改不了浏览器的媒体查询结果）。
- 窄屏是在桌面 Chrome 里按 360 / 390 / 530 / 721 四种视口量过布局与遮挡（19 个可点元素两两无重叠，海占 62%～71% 屏高），**没上真机**，软键盘弹起那一段还没验。
- 导入接口只到「契约 + 零依赖本地桥 + 页面内探针」这一层，**B站 / 虎牙的真实抓取插件没写**，也不打算在这个仓库里写（要平台权限）。
- 打赏的三个物件是本地玩法，没有接任何平台的支付/礼物接口；「打赏」这两个字在这里只意味着往海里倒东西。
- 鲸鱼娘是正身构图（不左右翻转），所以她**只朝右吃**——弹幕流向也是从右往左，这是同一个设定的两面，但想看她掉头游的话得再改碰撞与追食方向。
- 仓库名里的 `swimmng` 是公冰蓝打字太快留下的，保留了。
