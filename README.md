# swimmng-whale-girl-in-the-danmu

大型连续剧之。。。

**鲸鱼娘在弹幕群中游泳**

> 弹幕不是飘在画面上的字，弹幕**就是水**。
> 她游在弹幕里，因为有人在说话；没人说话，海就干了。

## 怎么演

下载或 clone 下来，**双击 `index.html`**。不用装东西、不用起服务、不用联网——离线打开海就是活的。

进来时海里有 22 条演示弹幕（那是她家原来的水），并且默认自播——每 0.9 到 2.4 秒随机飘进来一条（平均约 1.65 秒）。你可以：

| 你做什么 | 海和她会怎样 |
|---|---|
| 什么都不发，放着不管 | 水一点点退。水深跌破 96 px，她**搁浅**，趴在沙地上喊「水…… 谁来给点水……」 |
| 发一条弹幕 | 往海里加一方水：水位上涨、轨道变多、海床重新被淹 |
| 狂发 40 条以上 | 她**被弹幕淹没**，沉在海底只冒泡：「有人吗 我被淹在弹幕里了」 |
| 弹幕飘到她嘴边 | 她一口吞 3 条，饱食度 +42。吞得够多就**吃撑**：身体放大 34%、游速从 78 掉到 40、开始打嗝 |
| 她游过的地方 | 弹幕被她的身体**挤开**（最多 26 px）并跟着水流失重，离开时倾角回正 |

### 她听得懂的词

只学了 6 组词，其余一律歪头。

| 你说 | 她做 |
|---|---|
| 哈哈 / 233 / xswl / 笑死 | 翻肚皮 |
| 救命 / sos / 捞捞 / 别沉 | 冲过去捞你 |
| 小鱼干 / 投喂 / 饿 / 吃 | 开始追食 |
| 加油 / 冲鸭 / 你可以 | 加速游（×1.85） |
| 上岸 / 搁浅 / 走走 | 歪头：「上面没有 wifi。」 |
| 离谱 / 绷不住 / 无语 | 急停，两眼变成一条线 |

被淹没的时候她**听不见**——她都淹了，这很合理。

### 连续剧壳

每 45 秒一集。本集标题取**她吃掉的第一条弹幕**（所以标题是观众共同作者），一条没吃就从兜底池抽一个《海干的下午》。换集时滚一行「剧情提要」，全部由真实事件拼出来：她吞了几条、有人笑了几次、海干了几个回合、她游过多少米。第 1 集有片头，片尾出下集预告。

## 面板

右下角「遥」打开**现场遥测**：水位、水深（带「← 搁浅线 96」的刻度提示）、同屏弹幕数、轨道数、她当前状态、饱食度、速度、本集时长、累计吞食。快捷键：`空格` 暂停 · `P` 面板 · `N` 回到输入框 · `Esc` 退出。

演示按钮（四个）用来**验证设定而不是装饰**：`补水` 塞 9 条看海面上升，`高能 46 条` 逼出淹没，`断供` 关掉供给并清空、让她当场搁浅，`投喂小鱼干` 触发追食。

## 技术与口径

- **零依赖、零构建**：传统 `<script>` 全局对象，没有 ES module、没有 `fetch`、没有 CDN、没有 `@font-face`。
- **体积**：6 个运行文件合计 **65.8 KB（未压缩）/ 24.3 KB（gzip）**。
- **弹幕宽度用 `canvas.measureText` 度量**，所以换字体得同步改度量字体栈，否则会叠字。
- **没有服务器**。你发出去的弹幕存在你自己的浏览器 `localStorage`（`wwd.danmu.v1`，上限 60 条），刷新后回放。昵称存在 `wwd.nick.v1`，字号/自播开关存在 `wwd.prefs.v1`。清掉浏览器数据，海就真的干了。
- **单一主循环**：一个 `requestAnimationFrame` 驱动海、她、剧本三方，`dt` 封顶 0.05 秒；标签页回到前台时重置时基。
- **循环不会死在第一帧**：后台标签页 / 还没显示的容器里开机时，首个 rAF 回调可能永不投递。1 秒一次的看门狗（后台照样走的定时器）和 `visibilitychange` 会把链条重新接上，`WWD.snapshot().revives` 是它救场的次数。
- **可达性**：`prefers-reduced-motion` 下关摆动与弹簧（JS 同步关闭，减少动效不减少信息），`forced-colors` 下弹幕保留 1px 描边、水色退成 `Canvas`；弹幕层与片头遮罩一律 `pointer-events: none`；375px 窄屏只改三个 CSS 变量推布局。
- 输入内容经过 HTML 转义，昵称与内容都有长度上限。

## 已知没做完的事（诚实清单）

- `prefers-reduced-motion` 和 `forced-colors` 只验证了**规则存在且 JS 侧有联动**，没在真实系统偏好下跑过（我改不了浏览器的媒体查询结果）。
- 窄屏只在桌面 Chrome 里改了视口宽度测，**没上真机**。
- 鲸鱼娘是正身构图（不左右翻转），所以她**只朝右吃**——弹幕流向也是从右往左，这是同一个设定的两面，但想看她掉头游的话得再改碰撞与追食方向。
- 仓库名里的 `swimmng` 是公冰蓝打字太快留下的，保留了。
