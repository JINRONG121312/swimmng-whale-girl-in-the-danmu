## 1 · 自我介绍

我是公冰蓝，独立开发者，学生。GitHub `JINRONG121312`，团队 oceanplay（基本上就是我）。
前两个项目里已经交代过我的情况，这里不重复——那两条也正是这个作品的前身：

- **鲸鱼娘在我摸鱼时游泳了**（`whale-in-my-web`）——那条「大肥鱼」和它的角色语汇；
- **弹幕套件**（danmaku-kit 方向）——弹幕怎么排版、怎么不叠字、怎么度量宽度。

这个作品把两条线拧在一起：**弹幕不再飘在画面上，弹幕就是水本身。**

## 2 · 作品是什么（一句话）

一个零依赖单页互动剧：**直播观众、主播和挂在直播间背景的 OBS 叠层**用它时，弹幕的密度直接变成海水的体积——发弹幕＝加水，冷场＝海退，刷屏＝她被淹没；她游在弹幕里，飘到嘴边的字她一口吞掉，吞得够多就吃撑变慢；而弹幕里的关键词是她的指令。

它同时是一个**平台无关的实时弹幕导入接口**（`proto: 1`）：任何平台、任何语言写的插件，只要能吐出 `{nick, text, kind, gift}` 这个形状，就能把真弹幕灌进这片海。

## 3 · 为什么做

这是一个游戏，但我造着玩的时候不想让它只是个游戏。

弹幕这个东西平时是背景噪音——它飘过去，你看不见第二条。我把它的物理关系改成一个因果句：
**有人在说话，海才存在。** 于是三件事同时成立：

- 冷场不再是抽象的「没人理」，而是海一点点退干、她趴在沙地上喊「水…… 谁来给点水……」；
- 刷屏不再是「热闹」，而是她被你淹在海底只冒泡：「你们能不能 稍微 冷静一点」；
- 每一集的标题取**她吃掉的第一条弹幕**，所以剧情是观众共同署名的。

再把导入接口做进去之后，它就不只是「我做的一个网页」了：**接上哪个平台，它就是那个平台的直播皮肤。**
这是我觉得它真正有意思的地方，也是我在这里寻求合作的原因——它吸睛，而且它愿意被接走。

## 4 · 怎么用（5 步以内）

1. **打开** https://whale-danmaku-sea-k9qghxjx4u5.qoder.website/ （或者 clone 下来双击 `index.html`，离线也能跑）。
2. **发一条弹幕** —— 输入框打字，回车。水位上涨、轨道变多；她听得懂的 6 组词会让她当场演一下。
3. **按 `断供` 或关掉「弹幕自播」**，看海自己退干、她搁浅——这是本作最想让你看到的那一秒。
4. **点「打赏」** 送一颗爱心或一块巧克力：礼物本身是一条弹幕，得飘到她嘴边被她**吃掉**才生效（小鱼干例外，落地就倒水）。
5. **接你自己的弹幕源**：起 `node scripts/bridge.js 8788`，页面带 `?ws=ws://127.0.0.1:8788`，然后往 `POST /push` 发 JSON。契约全文在 [`docs/host-api.md`](host-api.md)，按你平台的字段名映射一次即可。

快捷键：`空格` 暂停 · `P` 现场遥测 · `C` 参赛证书 · `N` 回输入框。

### 它改掉的真实问题（都有数字）

1. **循环死在第一帧。** 后台标签页 / 还没显示的容器里，首个 rAF 回调可能永不投递，链条断死在启动。
   → 1 秒看门狗 + `visibilitychange` + `pointerdown/keydown/focus` 三条唤回路。
2. **预览面板把定时器也冻住。** 上一版线上页面在 Qoder 预览容器里 50 秒不动（实测 `sinceFrame 49975`、`revives 0`），因为唯一的救场手段是个冻住的 `setInterval`。
   → 加交互唤回，并写进 README 的口径。
3. **她偶尔瞬移。** 实测：视口从 1145 px 收到 725 px 时她**一帧横移 443 px**（边界钳位），搁浅那一步是把海床坐标直接赋值。
   → 改成按新旧比例搬位置（复测 297 → 202，精确等于 ×0.679）、搁浅改成滑落（复测强制退潮 900 步，`swim 245 / beach 655`，单步最大位移 **dx 2 px / dy 4 px**）。
4. **手机端她坐在输入框上。** 根因是 CSS 里硬写了 `--ui-h: 128px`，而窄屏发送条实际折成三行、真实高 **193 px**；海层又铺满整个视口，海床线落在控件底下。
   → 高度改由 JS 量（`--ui-h` 133 px、`--dock-h` 189 px），海的底边让给这条控件带。390×844 复测：海高 522 px（占屏 62%），`.stage` 底边 == `.dock` 顶边，19 个可点元素两两矩形**零重叠**。
5. **接口层 5 个真 bug**（都是取证时撞出来的）：本地桥 `upgrade` 参数顺序反了（第一个页面就连不上）、发标量帧丢引号、事件镜像把事件名覆盖成协议名、无文案的礼物被当畸形丢掉、真弹幕让位时把「自播关」写进了本地偏好（下次打开页面海是死的）。
