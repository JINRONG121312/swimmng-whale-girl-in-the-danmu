## 角色

你是一名给「把整屏弹幕当海水」的网页互动玩具做视觉的设计工程师。
产物是内联进单页的 CSS + 一份写死在 JS 里的参数表。

## 一句话立意

**弹幕不是飘在画面上的字，弹幕就是水。**
她游在弹幕里，因为有人在说话；没人说话，海就干了。

## 硬约束（不可改）

1. **零依赖、零构建**。双击 `index.html` 用 `file://` 打开必须能跑 —— 所以是传统 `<script>` 全局对象，不用 ES module、不用 `fetch`、不用 CDN。四个文件按 `sea.js → whale.js → drama.js → app.js` 顺序加载，前三个只挂全局对象，装配只在 `app.js`。

2. **弹幕就是水位**：水位 `--sea-top` 由弹幕吞吐推导，JS 每帧写进 CSS 变量。CSS 里**不得出现水位的具体 px**（只准留 `var(--sea-top, 78px)` 这种兜底）。

3. **JS 与 CSS 的变量契约**（CSS 只负责把这些属性组装成 transform，不得在同一个属性上再叠别的变换）：

   | 谁 | JS 写的变量 | 谁消费 |
   |---|---|---|
   | 每条弹幕 | `--x` 水平位置 · `--y` 轨道 + 被挤开 · `--rot` 被水流带的倾角 · `--s` 吞入时的缩放 | `.dm` 的 `translate3d().rotate().scale()` |
   | 鲸鱼娘 | `--wx` `--wy` 位置 · `--rot` 俯仰 · `--sc` 吃撑放大 | `.whale` 位移，`.rig` 缩放 |
   | 海 | `--sea-top` 海面 y · `--sea-floor` 海床高 | `.sea-water` `.sea-bed` `.sea-surface` |
   | 气泡 | `--x` `--y` `--r` `--drift` | `.dm-bub` |
   | 文字 | `--dm-font`（见第 4 条）· 台词 `--say-ttl` · 片头 `--card-ttl` | `.dm` / `.say` / `.card` |

4. **弹幕字号只能由 JS 写**：`--dm-font`（紧凑 12 / 标准 14 / 舒适 17）。禁令只覆盖**弹幕相关规则**（`.dm` 及其风格变体）；页眉、面板、按钮这些 UI 文字该多大还多大，不然遥测面板会跟着水位一起抖。

5. **禁止 `@font-face` 与 `url()` 字体**。弹幕宽度靠 `canvas.measureText` 用宿主字体度量，换字体测宽就不准，会叠字。字体栈固定：`system-ui, -apple-system, "Segoe UI", "Microsoft YaHei", sans-serif`。

6. **浅底墨字**。水色是亮蓝，文字统一墨色 `#14181F`；不允许大面积白字（晃眼，且和 danmaku-kit 的口径不一致）。

7. 必须过 `@media (prefers-reduced-motion: reduce)`：关尾鳍/胸鳍/呆毛摆动、关海面波纹、关掉入与浮动，水位与饱食度改成面板上的数字直读。**JS 侧同步**：`sea.reduced()` 为真时不做上下浮动、不做被挤开的弹簧、身体障碍关掉——减少动效不是减少信息。

8. 必须过 `@media (forced-colors: active)`：高对比下弹幕保留 1px `CanvasText` 描边分隔，水色与海床退成 `Canvas`，海面改 2px 实线（不是 10px 墨条），角色身体保留描边。

9. `.stage` / `.sea` / `.card` 一律 `pointer-events: none`。**任何情况下不得挡住发送框和按钮的点击。**（这条踩过坑：片头遮罩没加 `pointer-events`，整屏被 72% 墨色蒙住且点不动。）

10. 不假设 `hover` 存在；375px 宽要能玩。窄屏只改 `:root` 里的 `--whale-w / --ui-h / --cue-lift` 三个量，布局靠它们推。

11. 角色素材原创。鲸鱼娘是从 whale-in-my-web 同一作者的大肥鱼改画而来的**正身构图**，未使用任何第三方同人素材。

## 风格槽位（← 主要改这里）

- **海的气质**：清凉泳池 / 深海 / 果汁汽水 / {{＿＿＿}}
  （当前默认：清凉泳池 —— `#c6eafa → #8fccec → #559fd2` 三段亮蓝 + 白色高光，不做黑暗深海）
- **弹幕在水里观感**：
  - 底：纸片白 `#FFFDF5` / 半透明水色 / 无底纯描边 → 默认 **纸片白 + 1px 墨描边**（浅底墨字，任何水色上都读得清）
  - 形状：胶囊 / 圆角纸片 / 完全无底 → 默认 **圆角纸片，4px**
  - 4 种风格由观众在发送框里选：`plain` 一片纸（去描边）· `bubble` 对话气泡（999px + 小尖角）· `spark` 高能（`#ffd166` 底 + 加粗）· `torn` 撕纸（`clip-path` 斜切上下边）。`auto` 是随波逐流，按上一条轮换。
  - 被鲸鱼挤开时要不要**明显变形**？默认 **要**：`--y` 最大 26px、`--rot` 最大 ±7deg
- **尾迹（wake）**：水波纹线 / 一串气泡 / 只留残影 → 默认 **气泡串**，直径 3–8px，常态 6 个/s，被淹没时 14 个/s
- **鲸鱼娘的构图**：**正身**（不是侧身）。理由：侧身构图下耳机带和麦克风杆必然横穿眼睛和嘴，公冰蓝看过截图说「脸部穿模有点丑」。正身版本的约定：
  - 耳机带是**完整跨过头顶的一条弧**（`M30 94C29 40 171 40 170 94`），两个耳罩对称挂在左右 `x=18 / x=161`
  - 麦克风杆**只从左边耳罩下方弯出去**，止于 `(46,139)`，绝不横穿嘴
  - 双眼对称（cx 76 / 124），两枚腮红对称，嘴居中（92→108）
  - 因为左右不翻转，**她的嘴在身体正中**，弹幕从右边流进来被她吞——追食方向固定朝右，不再按 heading 翻转
- **状态类**（挂在 `#whale` 上，7 个）：`is-swim` 常态 / `is-fat` 吃撑 / `is-drown` 被淹没 / `is-beach` 搁浅 / `is-eat` 正在吞 / `is-belly` 翻肚皮 / `is-tilt` 听不懂歪头
  优先级：`drown > beach > fat/swim`，动作（eat / belly / tilt）只在前两态之外才抢戏。
- **表情**（`data-face`，4 个值）：`open` 张嘴 / `happy` 弯眼 / `flat` 一条线 / `worried` 一条线 + 泪。缺省是睁眼微笑。
- **连续剧壳的腔调**：正经 CCTV 纪录片腔 / 土味短剧腔 / 欠揍的旁白腔 → 默认 **土味短剧腔**（「本集：《她吃了三条弹幕》」）
- **片头/片尾字幕**：片头只在第 1 集出现；每换一集滚一行「剧情提要」（用真实事件拼：吞了几条、笑了几次、海干了几次、游过几米）；片尾出「下集预告」。
- **观众自己发的那条要不要不一样**？默认 **要**：2px 玫红描边 `#E5497A`
- **听不懂的词怎么反应**：默认 `is-tilt` 歪头 8deg + 一句「这是什么意思 / 嗯？ / 听不懂但我大受震撼」
- **要不要声音**？默认 **不要**（零依赖 + autoplay 限制）

## 自检清单（已逐条回答，实测数据来自浏览器 DOM 取证）

取证方法：用 `browser-use` 打开 `file://`，靠 `evaluate_script` 读 DOM 与物理量。**后台标签页的 rAF 会被冻结**（实测 `movedPx = [0,0,0]`，这种位置数据一律判无效），所以 `WWD.tick(dt, n)` 提供确定性步进、`sea.probe()` 提供读数——下面所有数字都是这么来的。

- **离线打开，海是活的吗？控制台零报错？** 是。`file://` 直开，四个 `<script>` 全部同步加载，控制台无 error；`node --check` 四个 JS 全过。
- **一条弹幕都不发、放着不管——她会不会真的搁浅并喊救命？** 会。断供 + 700 步后：`beached true`、`depth 2px`、`water 0.003`、`lanes 0`、class `is-beach`、脸 `worried`、她在 y=749（海床 785），台词「水…… 谁来给点水……」，提要「海干了 1 次，是她上岸的理由」。
- **狂发 46 条——她会不会真的被淹没、只冒泡？** 会。`live 58` → `base drown`、速度 0、气泡 14/s、台词「有人吗 我被淹在弹幕里了」；此状态下关键词反应**有意**不响应（她都淹了，听不懂很正常）。
- **6 组关键词各触发一个不同动作？** 全中且互不相同：`belly→is-belly/happy`、`rescue→is-eat/open`、`chase→is-eat/open`、`boost→is-swim/happy`、`surf→is-tilt/flat`、`freeze→is-tilt/flat`，台词各自正确。不认识的词歪头 + 「这是什么意思」类台词。
- **吃满 100 饱食度，身体变大、速度变慢、会打嗝？** 14s 内 `eaten 12`、`full 99`、`fat 0.97`、`--sc 1.329`、速度降到 25、`burped 2`、`base fat`，提要出现「饱食度 81，她的肚子把三条弹幕挤到了轨道外」。
- **水真的是由弹幕构成的吗？** live 从 0 涨到 20 时：`water 0.546 → 0.888`、`depth 386 → 628px`、`lanes 12 → 21`。她作为障碍物实测把弹幕挤开 27–30px（重叠样本 87–167 次/帧）。
- **自播放着不管 70s 会怎样？** 稳态 `live 4–7`、水位 21–40%、水深 148–271px（不再贴着搁浅线）、`eaten 25`、慢慢从 `swim` 转 `fat`、未搁浅未淹没，连续剧进到了第 2 集并出提要。
- **375px 宽：发送框可用、弹幕不叠字、她不出屏？** 窄屏断点的 CSS 已生效（`--whale-w: min(58vw,190px)`，发送条换两行），`.sea-field` 宽度按容器实测，超上限时挤最老的。**要说明**：我只在桌面 Chrome 里改了视口宽度测，没在真机上跑过。
- **`prefers-reduced-motion` 打开后还看得懂吗？** CSS 规则存在，JS 侧有 `sea.reduced()` 联动（关浮动、关弹簧、关障碍物）。**未做运行时模拟**——我没法在浏览器里改系统偏好，`matchMedia` 一直是 `false`。同理 `forced-colors` 也只有 CSS 规则，没实测。
- **体积？** 实测 6 个运行文件合计 **65.8 KB（未 gzip）/ 24.3 KB（gzip -9）**——数字是 `node scripts/selfcheck.js` 跑出来的，改了代码重跑一次就会刷新：

  |---|---|---|
  | `index.html` | 7.7 KB | 3.0 KB |
  | `src/ocean.css` | 16.0 KB | 4.5 KB |
  | `src/sea.js` | 13.9 KB | 5.3 KB |

  | `src/drama.js` | 6.2 KB | 2.7 KB |
  | `src/app.js` | 9.5 KB | 3.9 KB |

  比 danmaku-kit 那条 4 KB 预算大得多——但那个是要嵌进别人网站的 SDK，这个是一整幕连续剧，海、角色、剧本、UI 四层都在这一个包里且没有任何外部依赖。gzip 24 KB 仍然是「一次握手就够」的量级。
